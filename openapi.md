# OpenAPI

The live OpenAPI document for Callmeter is published at:

**https://api.callmeter.dev/openapi.json**

Fetch it anytime:

```bash
curl -sS https://api.callmeter.dev/openapi.json | head
```

This repository does not vendor a full OpenAPI snapshot. Treat the live URL as the source of truth for paths, schemas, and security schemes.

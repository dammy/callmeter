# Security Policy

## Supported versions

The live Callmeter API and MCP endpoint at `https://api.callmeter.dev` are the supported surface.

## Reporting a vulnerability

Please report security issues privately to **dammyg@gmail.com**.

Do not open public GitHub issues for vulnerabilities that could expose customer keys, billing, or payment flows.

Include:

- Description of the issue
- Steps to reproduce (if safe)
- Impact assessment
- Your contact details for follow-up

We aim to acknowledge reports within a few business days.
